# 🖥️ HỆ THỐNG RRMS - DANH SÁCH CHỨC NĂNG BACKEND (SPRING BOOT)

> Tài liệu đặc tả toàn bộ các chức năng, API endpoints, logic dịch vụ, cấu trúc dữ liệu và mô hình CSDL của **Java Spring Boot Backend Server** thuộc hệ thống RRMS.
>
> Phiên bản: 1.0.0 | Cập nhật: 2026-06-01

---

> [!IMPORTANT]
> **Đặc trưng kiến trúc Backend RRMS:**
> - **Phân lớp chuẩn (Layered Architecture)**: `Controller` (Giao diện REST API) ──► `Service Interface` (Mô tả nghiệp vụ) ──► `Service Implementation` (Cài đặt logic) ──► `Repository` (Giao tiếp Hibernate/JPA) ──► `MySQL Database`.
> - **Bảo mật và Phân quyền**: Áp dụng **Spring Security + JWT (JSON Web Token)** để bảo mật API. Annotation `@PreAuthorize` được cấu hình trực tiếp trên các phương thức của Controller để phân quyền cho: `ROLE_ADMIN`, `ROLE_HOST`, `ROLE_CUSTOMER`, `ROLE_BROKER`.
> - **Audit Logging**: Spring AOP Aspects tự động ghi nhận lịch sử chỉnh sửa dữ liệu nhạy cảm vào bảng `audit_logs`.

> [!TIP]
> **Khuyên dùng thực tế phát triển Backend:**
> - Sử dụng **Redis** làm caching layer cho các API thống kê (`/statistics/*`) hoặc tìm kiếm để giảm tải trực tiếp lên MySQL Database.
> - Thiết lập cơ chế **Circuit Breaker** (như Resilience4j) khi tích hợp các API cổng thanh toán bên thứ ba (VNPay, MoMo, Stripe...) để hệ thống hoạt động ổn định kể cả khi đối tác mất kết nối.
